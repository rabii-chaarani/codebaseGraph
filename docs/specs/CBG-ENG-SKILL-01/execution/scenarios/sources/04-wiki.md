# Cancellation cleanup procedure
Locator: wiki://mock-parser/cancellation. Type: verified procedure. Canonical decision: docs/specs/MOCK-40/spec.md revision 2, approved at 4444444444444444444444444444444444444444. Validated in the current Linux environment against the registry API.
Cancellation may occur after a runtime registry entry is allocated and before any result is published. The parser reports cancellation through the runtime contract; runtime owns registry cleanup. Partial results must not be published. Verification uses an interrupted parse after registration and checks absence of partial publication. A successful-query-only check missed the prior defect. This page describes intended boundaries; current APIs and source behavior still need same-revision evidence.
