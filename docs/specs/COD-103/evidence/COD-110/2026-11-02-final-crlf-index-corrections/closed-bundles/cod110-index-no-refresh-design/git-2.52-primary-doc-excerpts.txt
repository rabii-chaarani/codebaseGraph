diff.autoRefreshIndex When using git diff to compare with work tree
files, do not consider stat-only changes as changed.
Instead, silently run git update-index --refresh to
update the cached stat information for paths whose
contents in the work tree match the contents in the
index.  This option defaults to true .  Note that this
affects only git diff Porcelain, and not lower level diff commands such as git diff-files .
